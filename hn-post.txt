```
Show HN: Shortify AI – Turn a 1-line idea into a short drama video (open-source)
```

### 描述文字（第一段评论）

I built an open-source pipeline that takes a creative prompt like "a time-traveling maid lands in a modern office" and outputs a complete short drama — script, illustrated storyboard, multi-voice dubbing, and 1080p video.

**How it works (4-stage pipeline):**

1. **AI Scriptwriter** (GLM / DeepSeek) → generates structured script with characters, scenes, and shots
2. **Image Generator** (Wan2.7 / CogView) → creates an illustration per shot
3. **Multi-voice TTS** (iFlytek / Edge-TTS) → assigns male/female/narrator voices per character
4. **Video Compositor** (FFmpeg) → Ken Burns camera effects + subtitles + BGM → final video

**The hard part:** AI video models fail ~10-15% of the time. A single failed shot used to produce a black screen that ruined the whole episode. The fix was a three-tier fallback that guarantees zero black screens.

**Tech:** Next.js 16, FFmpeg, PostgreSQL, multi-provider AI (Zhipu, DashScope, iFlytek)

**Try it:** npm install → configure GLM_API_KEY → npx tsx scripts/full-pipeline.ts
